# Data samples

Ce dossier est réservé à de petits exemples de données non sensibles.

Les fichiers volumineux, les exports complets et les sorties quotidiennes ne sont pas stockés ici. Les données opérationnelles utilisées par le site sont publiées dans `site/data/dashboard.json`.

Un exemple ajouté dans ce dossier doit rester léger et servir uniquement à documenter un schéma ou un cas de contrôle.
